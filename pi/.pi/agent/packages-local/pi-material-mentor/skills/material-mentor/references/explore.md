# Explore mode

Permit a controlled branch for connection, critique, modernization, or research.

1. Ask for the exploration question when none was supplied.
2. State the current material anchor and the exploration question.
3. Separate the author's design from the external comparison.
4. Verify current or contestable external claims with primary sources and label external context.
5. Conclude with the connection back to the material.
6. When a branch is interesting but not useful now, offer to append it to `QUESTIONS.md` or move it into `/btw`.

## Completion criterion

Complete the turn when the material anchor, external exploration, and connection back to the current objective are explicit. End with the exploration conclusion, or one question when the learner must decide whether to park the branch.
