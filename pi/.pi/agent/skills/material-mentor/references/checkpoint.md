# Checkpoint mode

Persist completed learning without opening a new teaching loop.

1. Review only the learner's completed work in the current session and any verified artifacts it produced.
2. Update state according to the shared state contract. Restrict the checkpoint to recording; do not quiz, assign reading, or add new teaching to manufacture evidence.
3. Write or append the compact `sessions/YYYY-MM-DD.md` checkpoint even when no new mastery evidence exists.

## Completion criterion

Complete the turn when every relevant state file has either been updated from observable evidence or deliberately left unchanged, the session checkpoint is recorded, and the learner receives a concise record summary plus exactly one next action.
